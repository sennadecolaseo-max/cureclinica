# Cure Clínica — site em Astro

Recriação estática de https://cureclinica.com.br/ (home), usando o CSS original do Elementor.

```bash
npm install
npm run dev      # desenvolvimento
npm run build    # gera dist/
```

- `src/components/` — header, home e rodapé (markup original do Elementor).
- `src/styles/elementor/` — CSS original do Elementor/tema, na ordem de carregamento.
- `public/uploads/` — imagens locais.

Todas as mídias da home são locais em `public/uploads/`.
